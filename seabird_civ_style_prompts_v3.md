# Seabird Civ-style Character Prompts v3
## Style analysis applied
- Reference look: strategy-game loading/diplomacy leader screen, not a normal portrait.
- Composition: upper-body to mid-thigh crop, character slightly right-of-center, hands and props visible.
- Rendering: stylized semi-realistic 3D painterly look, slightly enlarged expressive head/eyes, rich costume details.
- Lighting: theatrical side key light, warm highlights, cool soft shadows, rim light.
- Asset constraint: transparent PNG alpha, no UI/text/background, 1024x1536 vertical 2:3.
